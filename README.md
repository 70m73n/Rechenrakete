# Rechenrakete

Ein installierbares Mathe-Spiel für Kinder ab 8 Jahren. Richtige Lösungen bringen Sterne, Baupläne und neue Bewohner für die eigene Planetenwelt.

## Als App installieren

Die Web-App über eine HTTPS-Adresse öffnen und im Browser **Installieren** beziehungsweise **Zum Home-Bildschirm** wählen. Danach startet Rechenrakete wie eine normale App und funktioniert auch offline.

Auf iPad und iPhone die Seite in Safari öffnen, auf **Teilen** tippen und **Zum Home-Bildschirm** auswählen.

## Lokal starten

Unter Windows `local-server.ps1` ausführen und anschließend `http://localhost:8080` öffnen. Service Worker funktionieren lokal über `localhost`.
